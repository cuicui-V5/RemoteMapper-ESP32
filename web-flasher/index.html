Direct Comparison

告别传统纯软件方案的妥协与痛点

Windows 蓝牙驱动内核层过滤机制导致纯软件 Hook 方案无法完美兼容，RemoteMapper 采用硬件物理中继方案实现真正意义上的完美适配。

✕ 传统纯软件直连方案
  • ✕
    部分按键被系统内核丢弃：遥控器的「音量+ (0x80)」、「音量- (0x81)」、「返回 (0xF1)」被 Windows 自带蓝牙驱动（`kbdhid.sys`）过滤丢弃，应用层 Hook/AHK 完全截获不到。
  • ✕
    语音依赖虚拟声卡 (VB-Cable)：私有 ATVV 压缩音频必须二次路由转存，引入明显音频延迟且经常出现声道占用或采样率不匹配。
  • ✕
    安全与反作弊风险：如需过滤驱动必须强制开启 Windows 测试模式，极易触发各类竞技游戏（如瓦罗兰特、APEX、CF等）的反作弊封禁。
  • ✕
    开机与睡眠唤醒无解：PC 关机或深度睡眠时蓝牙接收器关闭，无法通过遥控器进行一键开机。

  • ✓

  • ✓
    免驱动硬件级 USB 麦克风 (UAC 1.0)：芯片内置 IMA-ADPCM 实时流解码，电脑识别为物理麦克风，支持语音按下瞬间自动注入快捷键与按键杂音智能消隐。
  • ✓
    即插即用 · 反作弊 100% 免疫：模拟标准免驱 HID 键盘与麦克风，无需在电脑端运行任何常驻后台或安装内核驱动，与原生物理外设无异。
  • ✓
    局域网 WOL 无线远程唤醒：关机或睡眠状态下，按下遥控器按键即可向电脑发送 Magic Packet 魔法包，实现沙发上一键无线开机。
Core Features

专为极致桌面体验打造的核心能力

从底层音频处理、多层按键状态机，到内置 Web 管理系统，每一个细节都经过精心打磨。

🎙️

免驱 UAC 1.0 麦克风

模拟 16kHz 16-Bit 单声道硬件级麦克风。支持按下瞬间唤起输入法快捷键，并在前段加入 150ms 杂音消隐区与 10ms 淡入平滑，彻底杜绝按键微动爆音。

🎛️

5 层独立宏映射系统

默认层 + 4 个自定义层。每个按键均支持单击、长按（200~2000ms）与双击（100~600ms），具备穿透继承、一次性层、闲置超时自动返回与 RGB 状态指示灯。

⚡

局域网远程开机 (WOL)

可将任意按键（甚至长按）设置为局域网网络唤醒魔术包（Magic Packet）。无论电脑处于关机（S5）还是睡眠状态，轻按遥控器即可无线开机。

🔊

多媒体直通与连续长按

完美支持标准 Consumer 媒体键码。音量增加/减少支持长按持续平滑调节，播放暂停、曲目切换原生响应，无需手动点按多次。

🌐

内置可视化 Web 控制台

ESP32 固件集成 Web 服务器，自带 AP 热点（RemoteMapper-AP）与 STA 局域网接入。手机或电脑打开网页即可修改按键映射，配置存储于 NVS 掉电不丢。

🧩

全系 ESP32-S3 硬件支持

开箱兼容市场上主流 ESP32-S3-WROOM-1 开发板，包括 N16R8（16MB Flash/8MB PSRAM）、N8R8、N8R2、N4R2 等，刷机网页自动智能匹配。

Step-by-Step Guide

刷机完成后快速上手指南

仅需简单 5 步，轻松完成蓝牙遥控器配对、Wi-Fi 局域网接入与按键映射定制。

1

手动按【RST】按键重启设备

固件写入完成后芯片仍处于 Bootloader 状态。必须按一下开发板上的物理【RST】按键（或重新拔插一次 USB 线），板载 RGB 指示灯亮起即表示已成功开机运行。

2

连接热点 RemoteMapper-AP

使用手机或电脑打开 Wi-Fi 列表，搜索并连接到名为 RemoteMapper-AP 的热点（全新刷机默认无密码）。

3

打开内置 Web 控制台

在手机或电脑浏览器中打开管理后台地址。整个配置流程纯网页端操作，无需下载任何 App 或驱动。

http://192.168.4.1 可在后台「网络设置」中将设备连入家庭 Wi-Fi 局域网
4

蓝牙遥控器一键配对

拿起小米遥控器 2 Pro，同时按住 【主页键】+【菜单键】 持续约 3~5 秒（注意：该遥控器广播时无任何声光提示或指示灯反馈，属于正常物理特性），随后在网页后台点击「开始配对」搜索绑定。

5

配置按键映射与语音输入联动

① 打开 Windows 声音设置确认输入设备列表中已出现 RemoteMapper Mic（无需设为系统默认设备）；② 在微信输入法或讯飞输入法设置中，将语音麦克风单独指定为 RemoteMapper Mic；③ 将输入法语音热键与网页控制台保持一致（出厂默认预设为 右Alt + 逗号）。按住遥控器语音键说话即可体验零延迟转文字！

FAQ

常见问题与排查

问：点击“连接开发板”后弹出的串口列表中找不到设备，或连接提示握手超时？ 答：① 请确保连接的是开发板标有【USB】(Native USB) 的 Type-C 接口，不要插在 COM/UART 接口；
② 必须使用具备数据传输功能的 Type-C 数据线（纯充电线无法通信）；
③ 手动进入 Bootloader 模式（最关键）：用手指按住开发板上的【BOOT】键不放，按一下【RST】按键后松开，最后松开【BOOT】键，然后重新点击连接。
问：烧录完成后如何让设备正常运行？ 答：烧录完成后必须手动重启！因为绝大部分 ESP32-S3 开发板硬件设计上没有自动退出 Bootloader 的电路。因此烧录完成后请直接按一下开发板上的【RST】按键（或重新拔插一次 USB 数据线），设备即可退出刷机状态并正常开机启动。
问：我的开发板是 N16R8 还是 N8R8，选错会怎么样？ 答：网页刷机平台已实现硬件 JEDEC Flash ID 与 eFuse 自动探测！连接设备后会自动为您匹配最适型号。若 Flash 容量不匹配，系统会给出警告以防止死机。
问：升级固件后之前的配置和按键映射会丢失吗？ 答：在网页刷机平台选择「保留配置升级」模式即可！该模式只会写入位于 0x10000 的固件应用程序区，完全避开 0x9000 的 NVS 存储区，您的 Wi-Fi 配置、热点密码、按键映射以及遥控器配对记录会完好无损地保留。
