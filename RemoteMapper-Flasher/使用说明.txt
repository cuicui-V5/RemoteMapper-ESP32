================================================================================
           RemoteMapper-ESP32 免环境独立一键刷机包 - 使用说明
================================================================================

一、简介
本目录为独立绿色刷机包，已内置烧录工具（esptool）及官方预编译完整固件镜像。
电脑无需安装 Python、PlatformIO、Git 或任何开发编译环境，双击即可完成刷机。

二、支持硬件
- ESP32-S3-WROOM-1 N16R8（16MB Flash / 8MB Octal PSRAM，推荐）
- ESP32-S3-WROOM-1 N8R2（8MB Flash / 2MB Quad PSRAM）
- ESP32-S3-WROOM-1 N4R2（4MB Flash / 2MB Quad PSRAM）

三、快速使用步骤
1. 连接硬件：
   使用具备数据传输功能的 Type-C 数据线，连接电脑与 ESP32-S3 开发板的 USB/OTG 口。
   （注意：若开发板为双 Type-C 接口，请插在标有 USB 的接口，不要插在 COM/UART 口）

2. 进入刷机模式（防呆手势）：
   按住开发板上的【BOOT】键不放 -> 按一下【RST】键并松开 -> 松开【BOOT】键。

3. 运行刷机脚本：
   双击运行本目录下的【一键烧录.bat】（或 flash.bat），跟随全中文界面提示操作。

4. 刷机完成后配置：
   - 按一下开发板上的【RST】按键重启设备；
   - 手机或电脑搜索 WiFi 热点：RemoteMapper-AP（初始无密码）；
   - 浏览器打开后台：http://192.168.4.1 进行按键映射与蓝牙遥控器配对。

五、常见问题排查
1. 提示未检测到任何可用串口？
   - 检查 Type-C 数据线是否为纯充电线（纯充电线内部无数据引脚，电脑无法识别）；
   - 检查是否按正确手势（按住 BOOT -> 按 RST -> 松开 BOOT）进入了刷机模式；
   - 尝试插在电脑机箱后置原生 USB 接口。
2. 烧录过程中报错或串口打开失败？
   - 串口被占用：请关闭 Arduino IDE、PlatformIO Monitor、串口助手等占用该端口的软件；
   - 重新做一次 BOOT + RST 刷机手势。
